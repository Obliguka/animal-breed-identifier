Скриншоты для отчёта

Открой нужные URL, сделай скриншот (Win+Shift+S) и вставь в отчёт.

Как сделать скриншот: Win+Shift+S → выделить область → скриншот в буфере → Ctrl+V в отчёт

1. Langfuse — список трассировок

Открой http://localhost:3000, нажми "Traces" в левом меню.

Должны быть видны трассировки. Пример:

📸 Сделай скриншот этой страницы

Данные одной из трассировок:

{ "name": "text_predict", "input": {"prompt": "Answer in 3 words: what is the most popular pet?"}, "output": "The most popular pet among humans is dogs...", "usage": {"input": 54, "output": 36}, "time": "0.751 sec", "model": "tinyllama" }

2. LiteLLM — список моделей

Открой http://localhost:4000/models (через Postman/curl) или панель http://localhost:4000

📸 Сделай скриншот ответа /models

Или скопируй этот ответ как текст:

GET http://localhost:4000/models Authorization: Bearer sk-master-key-123 { "data": [ { "id": "tinyllama", "object": "model", "created": 1677610602, "owned_by": "openai" } ] }

3. LiteLLM — управление бюджетами

Открой панель: http://localhost:4000 → раздел Keys/Spend

📸 Сделай скриншот страницы управления ключами/бюджетом

Данные созданного ключа:

Ключ: sk-cBV... Статус: активен Ограничения: - max_budget: $0.0001/день - models: ["tinyllama"] - max_parallel_requests: 1 Текущее состояние после тестов: - spend: $0.00735 (превышен) - budget_duration: 1d Результат проверки: BUDGET EXCEEDED! HTTP 402 возвращается при превышении лимита

4. Проверка HTTP 402 (бюджет превышен)

Результат выполнения теста:

=== TEST: HTTP 402 Budget Exceeded === BUDGET EXCEEDED! BudgetExceededError caught: http_status=402 message=Дневной лимит бюджета исчерпан === SUCCESS: HTTP 402 is properly returned! ===
